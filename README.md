# מערכת לידים – מצפה כנרת

מערכת CRM לניהול לידים: עובדת בפלאפון ובמחשב, בלי חיבור לאינטרנט וגם איתו, ומסתנכרנת בין מכשירים.

- **האתר:** https://ab0583281470-droid.github.io/kineret-leads/
- **התקנה בפלאפון:** פותחים את האתר בדפדפן ובוחרים "הוסף למסך הבית".
- **נתונים:** נשמרים ב-Supabase (מאחורי כניסה). הריפו כולל קוד בלבד, בלי נתוני לידים.

## פיתוח
```bash
npm ci
npm run build      # בונה את dist/
npm run serve      # תצוגה מקומית: http://localhost:5177
```
הקוד כולו ב-`src/app.template.html`. כל דחיפה ל-`main` מעלה גרסה חדשה אוטומטית (GitHub Actions → Pages).

## גיבוי יומי
`npm run backup` שומר את כל הנתונים לקובץ דחוס בתיקיית `../backups` (מחוץ לריפו, 30 האחרונים).
דורש `.env.local` (ראו `.env.local.example`). שחזור: `npm run restore -- <קובץ>`.
